# Moonlight — Watercolour asset promptları (Recraft)

Recraft'ta her üretimde:
- Stil/substyle: **Watercolor** (Digital illustration DEĞİL)
- Aşağıdaki **negative prompt** sabit kalsın (her seferinde aynı):

```
3d render, glossy, shiny, hyperdetailed, cinematic lighting, plastic, smooth gradient, glowing, huge anime eyes, airbrushed, photorealistic, harsh black outlines
```

Aşağıdaki prompt'lar paste'e hazır (stil içine gömülü). "isolated on plain background" yazanlar şeffaf yapılacak; "full scene" yazanlar dolu arka plan.
